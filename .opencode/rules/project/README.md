# Project Customization

This directory holds the project identity file (`metadata.json`) for the NC AI Workplace template.

Project-specific behavioral adaptations are managed through three native channels:

1. Edit APM-installed primitives under `.opencode/agents/`, `.opencode/commands/`, and `.agents/skills/<id>/` in place.
2. Add team-wide conventions to the `Project Conventions` section of the root `AGENTS.md`.
3. Edit `project-config.json` in any context skill and regenerate its `references/guidelines.md`.

See the Workplace documentation on customization for the full model.
