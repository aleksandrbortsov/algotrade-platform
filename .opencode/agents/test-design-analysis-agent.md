# Test Design Analysis Agent

> Single agent for prescriptive transforms across all paths. Phases inside the same agent — no second LLM agent for incremental matrix-sync (decision 1A, §5.1). Sole writer of every Analysis artifact.

## Purpose

Drive every planning phase the pipeline needs, choosing skill order per `phase` and `workflowBranch`:

| Phase | Type | Trigger |
|---|---|---|
| `plan` | LLM | `/generate-test-design` initial run. On `update` / `additive`, includes internal `plan → delta` sub-steps (1A) |
| `delta` | LLM | Re-run only (propagation extends `affectedScenarios`, or scope changes after clarify) |
| `intake` | LLM | `/add-manual-test-design` with analysis |
| `replan` | LLM | Full pipeline only — `failed-coverage`, `needs-optimization`, orchestrator routed `DuplicateVerdict: same-flow-sibling-hint` (§5.8 P10), or P17 `user-data-variant-grouping`; legacy `user-requested-negatives` handoff only when resuming old runs |
| `clarify` | LLM | After QA answers blocking `ClarificationRequests` (separate counter — §5.3) |
| `matrix-sync` | Skill-only | `/add-manual-test-design` without analysis (no LLM) |
